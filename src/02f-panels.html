The spreadsheet layer

Every function the class workbooks use, the modern name for each, the keystrokes that make array formulas work, and the traps that return a plausible wrong number instead of an error.

The sixty-second version
  1. All nine workbooks share one eight-step skeleton. Steps 1–4 and 7–8 never change; only the instrument and its weights do.
  2. The class files use the legacy function names — NORMSINV, NORMSDIST, STDEV, COVAR. They still work, but COVAR is the population version while STDEV is the sample one, which is why the two disagree in the fifth decimal.
  3. MMULT and TRANSPOSE need Ctrl+Shift+Enter in Excel 2019 and earlier, or you silently get the top-left element and a portfolio σ that is far too small.
  4. varcovar() is a VBA function shipped with the course files, not real Excel. Three ways to rebuild it are below.
  5. No PRICE, YIELD or MDURATION anywhere — this course discounts every cash flow at its own spot rate, so you build the column.
=MMULT(TRANSPOSE(w),mu) + NORMSINV(a)*SQRT(MMULT(MMULT(TRANSPOSE(w),Om),w))

The build order of every class workbook

All nine workbooks have the same skeleton. Recognising it means you can rebuild any of them from a blank sheet in about five minutes.

Legacy names, modern names, and the one real difference

Used in classModern equivalentDifference
NORMSINV(p)NORM.S.INV(p)none — identical
NORMSDIST(z)NORM.S.DIST(z, TRUE)the modern one needs the TRUE; with FALSE it returns the density instead
NORMINV(p,μ,σ)NORM.INV(p,μ,σ)none
NORMDIST(x,μ,σ,c)NORM.DIST(x,μ,σ,c)none
STDEV(range)STDEV.S(range)none — both divide by n−1
STDEVP(range)STDEV.P(range)none — both divide by n
COVAR(x,y)COVARIANCE.P(x,y)the legacy COVAR is the POPULATION version — it divides by n, not n−1
TINV(p,df)T.INV.2T(p,df)both two-tailed; T.INV (no 2T) is one-tailed and signed
Workbook checkTwo of those rows collide. The class sheets build Ω with =STDEV(...)^2 on the diagonal — which divides by n−1 — and =COVAR(...) off it, which divides by n. That makes the off-diagonals 0.4% too small at n = 250. On the option example, Cov(dy, rS) = 6.682909×10−8 where the consistent sample value is 6.709748×10−8. The effect on VaR is in the fifth decimal place, so do not "fix" the class answers — but if you build your own sheet, pair VAR.S with COVARIANCE.S. A mismatched matrix can in principle stop being positive semi-definite, which makes SQRT of the portfolio variance return #NUM!.
=_xlfn.NORM.S.INV
If you see this prefix in a formula bar, the file was written in a newer Excel and opened in an older one that does not know the function. The additional-questions workbook has exactly this in cell B14. It still calculates in current Excel; the prefix is cosmetic.
NORMSDIST has no second argument
So there is no legacy way to get the density. That is why the class calculators compute it by hand as =EXP(-(d^2)/2)/SQRT(2*PI()). Modern: =NORM.S.DIST(d,FALSE).

The custom function the workbooks depend on

Not standard Excel{=varcovar(F5:H255)} → builds the whole variance-covariance matrix from a block of factor columns

This is a VBA user-defined function supplied with the course files, which is why they are saved as .xlsm and why macros must be enabled. It is not available in a blank workbook. Three ways to reproduce it:

Data → Data Analysis → Covariance
The Analysis ToolPak. Fast, but it writes a lower-triangular block of static values using the population divisor, and it does not update when the data change.
=COVARIANCE.S(INDEX($F:$H,,ROW()),INDEX($F:$H,,COLUMN()))
A live grid you can fill across and down. Verbose, but it recalculates and it uses the sample divisor consistently on and off the diagonal.
=MMULT(TRANSPOSE(dev),dev)/(n-1)
The matrix way, where dev is the block of deviations from each column mean. One array formula, gives the entire matrix, and is the actual definition of a covariance matrix.
Fine printThe third form is worth knowing for an exam: if a question gives you a small block of returns and asks for Ω, subtracting the column means and forming Xᵀ X / (n−1) is quicker by hand than nine separate covariances, and it makes the symmetry obvious.

Array formulas: the keystrokes that decide whether you get a number or a matrix

Ctrl+Shift+Enter
The deck says this explicitly for MMULT. In Excel 2019 and earlier, an array formula entered with plain Enter returns only the top-left element. No error, just a wrong number.
Select the output range first
To see a 3×3 MMULT result you must select 9 cells, type the formula, then press Ctrl+Shift+Enter. Selecting one cell gives you one number.
{braces} in the formula bar
Excel adds them itself to show a formula is an array. Typing braces yourself does not work — they become text.
Microsoft 365 dynamic arrays
Results spill automatically and CSE is unnecessary. A spill blocked by existing content gives #SPILL!. This is why the class files, written in an older Excel, still carry CSE instructions that you may not need.
σP far too small?
Check CSE first. A missing Ctrl+Shift+Enter on the nested MMULT silently returns w₁²Ω₁₁ instead of wᵀΩw, which for a diversified book is a small fraction of the truth.

Every function used in the course, by job

NORMSINV · NORMSDIST
The quantile and the CDF. zα for VaR, N(d₁) and N(d₂) for Black-Scholes, and the probability of a loss.
AVERAGE · STDEV · COVAR · CORREL
μ, σ, and Ω. CORREL does not appear in the class sheets but is how you sanity-check a covariance: ρ = Cov/(σ₁σ₂) must sit in [−1, 1].
LN · EXP
Log returns, continuous discounting, and d₁. Continuous compounding is used throughout the option and futures lectures.
SQRT
σ from a variance, √T scaling, and σ√T inside d₁.
MMULT · TRANSPOSE
μP = wᵀμ and σP² = wᵀΩw. Nest two MMULTs for the quadratic form.
SUMPRODUCT
Macaulay duration from periods and PV weights, in one cell. Also a TRANSPOSE-free alternative: =SUMPRODUCT(w,MMULT(Om,w)).
SUM · INDEX
Bond price from a PV column; pulling element i out of an MMULT result for component VaR.
MAX
Option payoffs at the binomial nodes: =MAX(0,$H$24-H25).
PI()
The normal density. Use it — not 22/7.
Goal Seek · Solver
Not used in the class files, but the way to invert Black-Scholes for implied volatility, or to find the futures position that minimises a hedged portfolio's σP. Solver is the right tool for the practice problem's "minimise the risk" instruction.
Concept checkNotice what is absent. No PRICE, YIELD, DURATION or MDURATION anywhere in this course — because those functions take a single yield to maturity and real settlement dates, and this course discounts every cash flow at its own spot rate over integer periods. =D3/(1+C3/100)^B3 filled down is doing something Excel's bond functions cannot do. Do not reach for MDURATION in an exam here; build the column.

The trap list

−1.96 for a 95% VaR
−1.96 belongs to α = 2.5%. A 95% VaR wants −1.644854. Using −1.96 overstates it by 19.2%. The lecture-3 portfolio slide prints this error.
Forgetting the /100 on dy
Spot rates are quoted in percent. =(B5-B4)/100. Omit it and every bond VaR is 100× too large.
σ where the label says σ²
The lecture-3 T-bill slide labels two standard deviations as variances. If a "variance" is around 0.0009 on daily yield changes, it is a standard deviation.
w order ≠ Ω order
The option workbook puts dy first, rS second. MMULT will not complain if you reverse w — it will pair the stock weight with the yield variance and return a plausible number.
Missing Ctrl+Shift+Enter
Returns the top-left element of the matrix product. The classic symptom is a portfolio σ that is far too small.
Mixing continuous and discrete
Continuous PV goes with duration −t; discrete PV goes with −t/(1+yt). The coupon-bond sheet mixes them and overstates VaR by 2.3%.
22/7 for π
Makes the density, and therefore Vega and Gamma, 0.02012% too small. =SQRT(2*PI()).
Scaling the whole VaR by √T
The mean scales with T, the volatility with √T. =mu*T+NORMSINV(a)*sd*SQRT(T).
Percentage return on a futures contract
Its initial value is zero. Work in money: w = [S₀ ; T·S₀].
STDEV^2 beside COVAR
n−1 on the diagonal, n off it. Pair VAR.S with COVARIANCE.S.
Annual σ with T in months
σ, y and T must share one period. The deck's own example uses 5% per month with T = 12 months.
LOG instead of LN
LOG is base 10 in Excel and scales d₁ by 2.3026.
Coupons before delivery in a futures price
Only post-delivery cash flows belong in 0FT. And the price must sit between their PV and their undiscounted sum.
Forgetting T in the financing row
A coupon-bond-futures weight vector's last element is +T×Σ(X·B), not Σ(X·B). The lecture-5 slide drops the T.
Your A4 sheetOnly four things from this panel are worth the space: NORMSINV(0.01) = −2.326348 and NORMSINV(0.05) = −1.644854; VaR = wᵀμ + z·√(wᵀΩw); mean scales with T, volatility with √T; and wrS − wdy/T = 1 for an option or forward (they differ by exactly 1 when T = 1). The rest you can rebuild.
